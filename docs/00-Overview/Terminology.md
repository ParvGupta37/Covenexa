# Terminology

| Term | Meaning |
|------|---------|
| Private Credit | Loans provided directly by private investment firms instead of banks. |
| Borrower | Company receiving the loan. |
| Lender | Organization providing the loan. |
| Loan Agreement | Legal contract defining the loan terms. |
| Covenant | Rule the borrower must follow during the loan period. |
| Covenant Breach | Violation of a covenant. |
| EBITDA | Company's operating earnings before interest, taxes, depreciation, and amortization. |
| Borrower Health Score | Overall AI-generated score representing borrower financial health. |
| Default Prediction | Probability that a borrower may fail to repay the loan. |
| Portfolio | Collection of loans managed by a lender. |
| Stress Testing | Simulating adverse scenarios to evaluate portfolio resilience. |
| Knowledge Graph | Graph database representing relationships between borrowers, agreements, covenants, and financial data. |
| RAG | Retrieval-Augmented Generation, combining retrieved knowledge with LLM reasoning. |
| AI Agent | Autonomous component responsible for a specific task within the system. |
| Copilot | Conversational AI assistant for interacting with portfolio data. |
