# Product Requirements Document (PRD)

## Product Name

Covenexa

## Objective

Build an AI-native platform that continuously monitors private credit portfolios and provides proactive covenant and borrower risk intelligence.

## Core Features

- Loan agreement ingestion
- AI document parsing
- Covenant extraction
- Financial statement analysis
- Borrower Health Score
- Default probability prediction
- Portfolio stress testing
- AI recommendations
- Portfolio dashboard
- AI Copilot
- Automated report generation

## Functional Requirements

- Upload loan agreements
- Upload financial statements
- Store portfolio data
- Analyze borrower performance
- Monitor covenant compliance
- Generate alerts
- Produce downloadable reports
- Answer natural language queries

## Non-Functional Requirements

- Secure
- Scalable
- Explainable AI
- Fast document processing
- Enterprise-ready
