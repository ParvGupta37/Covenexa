# Database Stack

## PostgreSQL

Stores structured business data.

Examples

- Users
- Borrowers
- Loans
- Financial Statements

---

## Neo4j

Stores relationships between:

- Agreements
- Covenants
- Borrowers
- Definitions
- Amendments

---

## Vector Database

Pinecone

Stores embeddings for semantic search.

---

## Object Storage

AWS S3

Stores uploaded files.

---

## Redis

Caching and task queues.
